The new test addresses an actual gap: existing CNPG render cases checked one configuration at a time and optional Barman recovery, but did not compare database specs and ownership across an ordinary application image update. It changes no chart/runtime behavior. It intentionally does not exercise PostgreSQL major changes, physical backups, live Helm rollback, UID/PVC preservation, or external operator failover.

Behavior defects already assigned W03/W05/W06/W07/W09 retain separate regression slices; W00 does not implement their fixes. New product contract tests are justified by meaningful failure modes, not by copying ADR prose into assertions.
