The dedicated manual signing workflow is restricted to the public repository's main branch, grants OIDC only to its signing job and signs an exact-source resolution. The verifier uses checksum-verified official Cosign3.1.3 and a locally pinned public trusted root exported from authenticated official TUF metadata. `sigstore-trusted-root-resolution.json` records signed-target length/digest validation. Real Cosign rejects the unsigned invalid-bundle probe; CLI fixtures reject a failed verifier, absent bundle, wrong source and unknown schema. No positive authenticated signing run was executed. Before a new release, the operator must run `toolchain-resolution` on the exact main commit and set `TOOLCHAIN_RESOLUTION_RUN_ID` to that successful run. Offline verification still binds its source/authority/artifacts and freshness; a run ID alone never establishes trust. The intentional sanitized hidden evidence uploads explicitly enable hidden files without changing unrelated release upload policy.
