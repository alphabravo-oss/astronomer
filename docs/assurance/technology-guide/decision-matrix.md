# Guide decision matrix

The [guide](https://technology-selection-guide.aws.ablabs.io/llms-full.txt) was retrieved on 2026-10-09; its digest/review date are in [components.json](components.json). These are summaries of its RFC2119 prescriptions, not quotations. A deliberate departure from MUST is not literal conformance. Version snapshots are historical; user direction selects latest stable through reviewed discovery/qualification, not automatic startup updates.

ADR abbreviations: [Flux](../../architecture/decisions/flux-native-delivery.md), [Frontend](../../architecture/decisions/frontend-application-stack.md), [Go](../../architecture/decisions/go-platform-tooling.md), [FIPS](../../architecture/fips-cryptography-boundary.md). [Contributor contract](../../../AGENTS.md), [compatibility contract](../../../deploy/release/compatibility.yaml) and [production values](../../../deploy/chart/values-production.yaml) own existing product choices where no separate accepted ADR exists.
